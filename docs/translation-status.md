# Translation Status

## Upstream Baseline

- JSXGraph version: `1.13.3`
- tag: `RELEASE-v1.13.3`
- commit: `7c2176d479ae256cb9d38265bce81fa18709d01f`
- license option: MIT

The `2026-10-09` source-symbol audit scanned 103 included upstream JavaScript
files after excluding the legacy VML backend and `src/unused/`. It found 2,591
source symbols: 2,540 are translated, 16 have explicit pure-KMP adaptations,
35 are platform/CAS/license exclusions, and none remain pending. All 2,556
in-scope symbols and all 2,029 API-surface symbols map to source-specific
Kotlin locations. The independent
[`portable-behavior-compatibility.json`](portable-behavior-compatibility.json)
audit verifies all 249 portable behavior slices for a weighted score of
`100.00%`; one host-specific slice is excluded from 250 assessed behaviors.
`src/math/numerics.js#glomin` remains excluded because its embedded license
conflicts with this MIT-only project. Symbol mapping and the portable behavior
score prove translation progress, not Stable behavioral qualification;
platform-owned, CAS, license, and upstream-defect boundaries below remain
authoritative. There are no known portable translation gaps in the pinned
baseline. References to qualification outside the 30-case Stable corpus do
not mean that the corresponding source behavior is untranslated.

## Stable Support Scope

Release `0.1.0` is Stable for the translated construction-document and
Compose rendering subset listed in the source map below: Point, Line,
Segment with an optional numeric or JessieCode-string fixed-length parent,
Circle including the three-Point circumcircle form, Midpoint,
OrthogonalProjection, PerpendicularPoint, Perpendicular,
PerpendicularSegment, Curve, FunctionGraph, Plot, Polygon, Text, three-point
Arc, four-point Arc with `useDirection`, Sector, Angle, and free Point
interaction with dependency updates and state restoration, including dynamic
Segment length, Midpoint and orthogonal-construction parent updates, and a
clamped dynamic string-radius Circle.

The Stable rating applies only to the explicitly listed symbols and
parent/attribute forms, not to the complete upstream file or full JSXGraph
API. See
[`stability-report.md`](stability-report.md) for qualification evidence and
[`translation-deviations.md`](translation-deviations.md) for unsupported
behavior.

The public `JsxGraphJessieCode.parse` and stateful
`JsxGraphJessieCode.createSession` entry points expose the translated,
resource-bounded JessieCode subset without a JavaScript engine. They remain a
preview outside the `0.1.0` Stable construction-document contract until their
own independent corpus and runtime qualification gates are complete. This
preview includes the source-mapped `view3d`, `point3d`, `line3d`,
`intersectionline3d`, `plane3d` wireframe, `curve3d`, `vectorfield3d`, `circle3d`,
`intersectioncircle3d`, `sphere3d`,
`surface3d`, `functiongraph3d`, `mesh3d`,
`axis3d`, `polygon3d`,
`polyhedron3d`, `transform3d`, and `image`
creator paths described below.

lower/upper function pair, exposes the cached signed area through `Value()`,
and recomputes dynamic rectangle count, approximation type, and interval
bounds.
BoxPlot emits a filled degree-one Plot Curve whose quantile, axis, and width
terms update dynamically; its outlier faces are resolved from CSS-pixel size
at the actual renderer viewport.
Comb emits an unfilled degree-one Plot Curve with `NaN` tooth breaks, dynamic
frequency/width/angle/reverse terms, and hidden coordinate endpoint helpers.
Inequality emits a filled degree-one Plot Curve from a Line half-plane or
finite FunctionGraph segments, with dynamic `inverse` and Board-bound closure.
VectorField emits an unfilled degree-one Plot Curve from dynamic vector and
mesh functions; its arrowheads are resolved from CSS-pixel size at the actual
renderer viewport.
SlopeField emits the same scene form after converting a dynamic scalar slope
to the exact upstream normalized direction; arrowheads default to disabled.
Tangent/Polar emit a constrained coefficient Line for the
Circle/Point and Curve/Point branches or an unconstrained Line reusing source
endpoints for the Line/Point branch; PolarLine remains Circle/Point-only.
TangentTo expands one Circle-or-Ellipse/source-Point request into the polar
Line, selected contact Point, and tangent Line while exposing the two
intermediate elements. Glider accepts one Line/Segment, Ellipse, or ordinary
untransformed non-Conic Curve parent, or numeric x/y plus that parent; Slider
expands into two hidden Points,
baseline, Glider, highline, optional label, and optional Ticks with the
translated value and snapping APIs.
Tapemeasure expands two coordinate parents into endpoint Points, a finite
Segment, an optional dynamic distance label, and optional equidistant Ticks.
The root exposes its endpoints through `subs`, its Ticks through `inherits`,
and its current distance through `Value()`/`V`.
Measurement creates one dynamic Text from a bounded prefix term. It tracks
element and function dependencies, computes dimensions and units, formats
scalar/coordinate/direction values, and exposes its source term, method,
prefix serialization, and parent list through the translated method map.
SmartLabel creates one dynamic Text from a Point, Line, Circle, Polygon, or
Angle. It selects the upstream parent-specific measure and placement rules,
keeps supported dynamic attributes live, and exposes value, dimension, unit,
and parent access through the translated method map.
Extrapolate exposes the four upstream sequence transforms and both iterative
limit paths as a pure Kotlin math API. Official fixtures cover convergent,
degenerate, divergent, and `NaN` inputs, mutation-driven estimates,
classification, and reliability. Raw Plot v2 is translated independently and
remains the default; explicit Plot v3 consumes Extrapolate for one-sided
coordinate limits.
Integral expands one translated Curve and a two-bound interval into four
helper Points, one filled Curve, and an optional value label. Fixed bounds
remain draggable, string/function bounds are hidden and constrained, and
`Value()` preserves interval direction.
Ellipse, Hyperbola, and Parabola interoperation through Tangent, Polar,
PolePoint, TangentTo, Normal, Intersection, OtherIntersection, and Glider is
covered through parent updates and removal. PolarLine remains Circle-only as
defined by JSXGraph `1.13.3`; the upstream-invalid Turtle and Glider-backed
Tangent/Normal forms return structured failures. These focused additions are
not part of the independently qualified `0.1.0` Stable corpus.

  MIT-compatible provenance or an independent implementation.

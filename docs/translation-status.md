# Translation Status

## Upstream Baseline

- JSXGraph version: `1.13.3`
- tag: `RELEASE-v1.13.3`
- commit: `7c2176d479ae256cb9d38265bce81fa18709d01f`
- license option: MIT

## Stable Support Scope

Release `0.1.0` is Stable for the translated construction-document and
Compose rendering subset listed in the source map below: Point, Line,
Segment with an optional numeric or JessieCode-string fixed-length parent,
Circle including the three-Point circumcircle form, Midpoint,
OrthogonalProjection, PerpendicularPoint, Perpendicular,
PerpendicularSegment, Curve, FunctionGraph, Plot, Polygon, Text, three-point
Arc, four-point Arc with `useDirection`, Sector, Angle, and free Point
interaction with dependency updates and state restoration, including dynamic
Segment length, Midpoint and orthogonal-construction parent updates, and a
clamped dynamic string-radius Circle.

Rows marked `Partially translated` remain accurate. The Stable rating applies
only to the explicitly listed symbols and parent/attribute forms, not to the
complete upstream file or full JSXGraph API. See
[`stability-report.md`](stability-report.md) for qualification evidence and
[`translation-deviations.md`](translation-deviations.md) for unsupported
behavior.

The public `JsxGraphJessieCode.parse` and stateful
`JsxGraphJessieCode.createSession` entry points expose the translated,
resource-bounded JessieCode subset without a JavaScript engine. They remain a
preview outside the `0.1.0` Stable construction-document contract until their
own independent corpus and runtime qualification gates are complete. This
preview includes the source-mapped `view3d`, `point3d`, `line3d`, `plane3d`
wireframe, `curve3d`, `circle3d`, `surface3d`, `functiongraph3d`, `mesh3d`,
`axis3d`, `polygon3d`,
`polyhedron3d`, and `transform3d`
creator paths described below.

`normal`,
`tangent`, `polar`, `tangentto`, and `polarline`. PolygonalChain,
Parallelogram, and RegularPolygon share the Polygon scene type;
PolygonalChain preserves an explicit open-border flag, Parallelogram exposes
its constrained helper, and RegularPolygon emits its generated helper
vertices with nested Point styling. Their independent
helper lifecycles are retained. RadicalAxis emits a Line whose implicit
constrained endpoints remain hidden from the scene. PolePoint emits one
constrained Point for a Circle/Line pair; the Ellipse/Hyperbola/Parabola Conic
forms remain pending. Ellipse, Hyperbola, and Parabola emit
`OBJECT_TYPE_CONIC` parameter Curves with constrained centers and quadratic
forms; Ellipse and Hyperbola expose foci and major-axis metadata, while
Parabola retains its focus and directrix dependencies. Derivative
emits a parameter Curve from a source Curve's numerical
slope, retaining parent metadata without a source-child removal edge. Normal
emits the source-mapped Line, Circle, FunctionGraph, parametric Curve, and
degree-one data Plot perpendiculars for a registered Point.
Spline emits a FunctionGraph using sorted natural-cubic interpolation and
metadata-only Point parents. CardinalSpline emits a parameter Curve with
dynamic tension and preserves the ownership distinction between existing and
generated Points.
RiemannSum emits a filled Plot Curve from one function or an ordered
lower/upper function pair, exposes the cached signed area through `Value()`,
and recomputes dynamic rectangle count, approximation type, and interval
bounds.
BoxPlot emits a filled degree-one Plot Curve whose quantile, axis, and width
terms update dynamically; its outlier faces are resolved from CSS-pixel size
at the actual renderer viewport.
Comb emits an unfilled degree-one Plot Curve with `NaN` tooth breaks, dynamic
frequency/width/angle/reverse terms, and hidden coordinate endpoint helpers.
Inequality emits a filled degree-one Plot Curve from a Line half-plane or
finite FunctionGraph segments, with dynamic `inverse` and Board-bound closure.
VectorField emits an unfilled degree-one Plot Curve from dynamic vector and
mesh functions; its arrowheads are resolved from CSS-pixel size at the actual
renderer viewport.
SlopeField emits the same scene form after converting a dynamic scalar slope
to the exact upstream normalized direction; arrowheads default to disabled.
Tangent/Polar emit a constrained coefficient Line for the
Circle/Point and Curve/Point branches or an unconstrained Line reusing source
endpoints for the Line/Point branch; PolarLine remains Circle/Point-only.
TangentTo expands one Circle/source-Point request into the polar Line, selected
contact Point, and tangent Line while exposing the two intermediate elements.
Ellipse/Hyperbola/Parabola interoperation through Tangent, Polar, PolarLine,
PolePoint, TangentTo, Normal, Intersection, and OtherIntersection remains
pending, as do Turtle and one-parent Glider forms. These focused additions are not part of the
independently qualified `0.1.0` Stable corpus.
